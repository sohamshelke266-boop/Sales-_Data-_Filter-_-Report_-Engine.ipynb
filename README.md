# Sales-_Data-_Filter-_-Report_-Engine.ipynb
Sales Data Filter & Report Engine
Project Overview
The Sales Data Filter & Report Engine is a Python project that uses NumPy and Matplotlib to generate, filter, analyze, and visualize sales data for multiple stores and products.

The project simulates monthly sales data for 10 stores over 12 months and generates reports to identify sales trends, high-performing stores, and best-selling products.

Objectives
Generate random sales data using NumPy.
Analyze monthly and quarterly sales.
Filter sales using Boolean masking.
Identify below-average stores.
Find the top 3 sales months.
Generate store-wise and product-wise reports.
Visualize sales data using graphs.
Technologies Used
Python
NumPy
Matplotlib
Google Colab
Features
1. Sales Data Generation
Creates random sales data for 10 stores across 12 months using NumPy.

2. Quarterly Sales Analysis
Divides the yearly sales data into four quarters: Q1, Q2, Q3, and Q4.

3. Boolean Filtering
Filters sales data using conditions and Boolean operators such as &, |, and ~.

4. Store-Wise Analysis
Calculates total sales for each store and identifies stores performing below the average.

5. Best 3 Months
Uses NumPy indexing to find the three months with the highest total sales.

6. Product-Wise Analysis
Generates sample sales data for five products and identifies the product with the highest total sales.

7. Sales Reports
Displays monthly, store-wise, and product-wise sales summaries.

8. Data Visualization
Creates graphs to compare monthly sales, growth targets, store-wise sales, and product-wise sales.
